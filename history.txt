- user: 让助手按计划实施。
- actions: 从零搭建 presentation/ 子工程：
    * package.json / tsconfig*.json / vite.config.ts / index.html / .gitignore
    * server/index.ts — Node http + WebSocket，维护权威状态、广播
      { currentIndex, seed, transitionStartedAt, slideDurations, ... }
    * src/slides.ts — 通过 ?raw 导入 ../../speech.txt，按段落+中文句号切分，
      生成 79 张幻灯片，按 SCENE_PLAN 映射到 sceneKind / sceneParams
    * src/particle/sceneShapes.ts — 72 套 SVG 图示模板（line/rect/circle/
      arrow/star/wave/spiral/brain/gear/bigDigit 等基础原语 + 每个 sceneKind
      对应的 sceneFn），用 DOM SVG getPointAtLength 把所有路径采样为
      ~2200 个目标点，按长度比例分配
    * src/particle/ParticleScene.tsx — Canvas 粒子渲染，每帧用
      easeInOutCubic + transitionStartedAt + timeOffsetMs 计算 t，叠加
      正弦扰动；场景切换时基于 seed 做 mulberry32 洗牌重新分配目标
    * src/sync/wsClient.ts — useSync hook，支持指数退避重连、serverTime
      校准时钟差
    * src/pages/AudiencePage.tsx / AdminPage.tsx — 观众/后台 UI，含双预览
      预览、进度条、已用时间、估算剩余时间、演讲稿高亮、键盘快捷键
    * src/main.tsx / App.tsx / styles.css
  完成后跑 npm run typecheck（通过）、npm run build（212 KB），启动生产
  服务并用 scripts/ws-smoke.mjs 验证 admin+2 observer 同步成功
  （SYNC_OK true）。
